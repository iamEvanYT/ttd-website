# <u>Time Travel</u>

This is a new mechanic that allows you to obtain old, retired crates with trading! Each crate has a rarity which determines the chance to win it!

To unlock a spin, you can either use a key or a lucky key.

To accommodate for free-to-play players, you can watch **5 ads** for a **FREE** key!

![](/blog/images/2025/06/RobloxScreenShot20250607_160906756.webp)
